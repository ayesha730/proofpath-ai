ProofPath AI — Product Requirements Document

Product Vision

Make it easier for students to discover opportunities that match their academic background, interests, and funding needs.

User Problem

Relevant scholarships, competitions, fellowships, and career opportunities are distributed across multiple websites, making discovery and eligibility checking time-consuming.

Target Users

Students seeking educational funding, international study, technical competitions, research opportunities, and career development.

Main User Flow

1. The user opens ProofPath AI.
2. The user provides their academic profile and interests.
3. The system searches its supported opportunity sources.
4. The system presents relevant results with available details and links.
5. The user reviews the official listing to confirm eligibility and application requirements.

Functional Requirements

- Accept a student's profile and opportunity preferences.
- Support multiple opportunity categories.
- Retrieve listings from configured sources.
- Rank results according to profile relevance.
- Display source information and application links when available.
- Clearly communicate missing or unverified information.

Reliability and Safety

- Do not present unverified eligibility as confirmed.
- Do not invent deadlines, benefits, or application links.
- Explain when a source is unavailable.
- Protect API keys and other secrets.

Success Criteria

A user can enter preferences, receive relevant opportunity results, review available details, and follow a listing's source link.

Current Status

This document describes the intended product. Features and success criteria must be checked against the actual implementation before submission.
